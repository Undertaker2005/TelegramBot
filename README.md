# Telegram-бот для вивчення англійської

Локальний навчальний застосунок з українським інтерфейсом, загальною та бізнес-англійською, тестом рівня, уроками, вправами, повторенням слів і нагадуваннями. Працює на Python 3.12+, aiogram 3 і SQLite; бот отримує повідомлення через Telegram long polling.

Навчання доступне лише англійською. У застосунку немає оплати, підписок, групових функцій, звітності роботодавцю чи інших мов. Відео додаються як перевірені HTTPS-посилання до уроків.

## Запуск у Windows

1. Встановіть Python 3.12 або новіший і створіть бота через [@BotFather](https://t.me/BotFather), командою `/newbot`. Збережіть токен локально — не надсилайте його в чатах і не додавайте до репозиторію.
2. У PowerShell з папки проєкту створіть та активуйте середовище:

   ```powershell
   py -3.12 -m venv .venv312
   .\.venv312\Scripts\Activate.ps1
   python -m pip install --upgrade pip
   python -m pip install -e ".[dev]"
   ```

3. Створіть `.env` з шаблону та заповніть секрети й Telegram ID:

   ```powershell
   Copy-Item .env.example .env
   notepad .env
   ```

   `BOT_TOKEN` — токен від BotFather. `ALLOWED_USER_IDS` обмежує бота вказаними числовими ID (для особистого запуску впишіть тільки свій ID). `MODERATOR_IDS` — allowlist модераторів; `SUPPORT_ADMIN_IDS` — адміністраторів звернень, наприклад `123456789,987654321`. Дізнайтеся власний Telegram ID надійним способом. Не вставляйте токен у командний рядок, публічні issue чи логи.

4. Необов'язково створіть окрему базу каталогу навчальних матеріалів і перевірте їх без підключення до Telegram:

   ```powershell
   python -m telegram_bot.main --init-content-db
   python -m telegram_bot.main --inspect-content-db
   python -m telegram_bot.main --check
   ```

5. Запустіть бота:

   ```powershell
   python -m telegram_bot.main
   ```

   Альтернатива після інсталяції: `english-learning-bot`.

База користувачів бота створюється в `data/bot.sqlite3`, а журнали — в `logs/bot.log`. Схема SQLite має версії та мігрується під час запуску. Дані курсів доступні як у JSON, так і в окремих рядках таблиць `lesson_catalog`, `vocabulary_catalog` і `exercise_catalog`. Каталогові таблиці можна оглянути в будь-якому переглядачі SQLite. Каталоги `data/`, `logs/` і файл `.env` ігноруються Git. Для роботи бота й нагадувань комп'ютер має бути увімкненим, під'єднаним до мережі, а процес бота має продовжувати працювати. Після зупинки процесу бот не приймає повідомлення й не надсилає нагадування; після перезапуску він продовжить роботу зі збереженої бази.

## Безкоштовний запуск для особистого користування

Для показу на захисті не потрібен платний хостинг. Запустіть long polling на власному Windows-ноутбуці: бот сам встановлює вихідне з'єднання з Telegram, тому домен, публічна IP-адреса й відкриті порти не потрібні.

1. У `.env` укажіть власний числовий Telegram ID у `ALLOWED_USER_IDS`, наприклад `ALLOWED_USER_IDS=123456789`. Це обмежує використання бота цим ID; порожнє значення залишає доступ відкритим для всіх, хто знайде бота. Для модераторських команд за потреби внесіть той самий ID у `MODERATOR_IDS`.
2. Запустіть `.\start_bot.ps1` у PowerShell з папки проєкту. Вікно має залишатися відкритим; зупинити процес можна `Ctrl+C`.
3. Відкрийте посилання на бота від BotFather у Telegram, натисніть **Start** і пройдіть onboarding.

Потрібні інтернет, увімкнений ноутбук і запущений процес. Якщо комп'ютер засне або скрипт зупиниться, бот тимчасово перестане відповідати й надсилати нагадування; після запуску він продовжить роботу з `data/bot.sqlite3`. Для особистого запуску це безкоштовніше й простіше за хмарний сервіс; не потрібно намагатися тримати бота в сервісі, який може засинати або не зберігати локальну SQLite-базу.

Для запуску без цієї консолі можна налаштувати Планувальник завдань Windows на старт `start_bot.ps1` після входу до системи. Це не зробить бота доступним, коли ноутбук вимкнено або перебуває в режимі сну.

## Перегляд каталогу матеріалів без Telegram-токена

Створіть окрему базу лише з курсами (без профілів учнів), перегляньте підсумок і відкрийте `data/course_catalog.sqlite3` у DB Browser for SQLite:

```powershell
python -m telegram_bot.main --init-content-db
python -m telegram_bot.main --inspect-content-db
```

Переглядайте таблиці `vocabulary_catalog` та `exercise_catalog`. Команди не потребують `.env` і не змінюють `data/bot.sqlite3`; якщо файл каталогу вже існує, наявні дані не перезаписуються. Вміст також доступний у [`content/courses.json`](./content/courses.json), вихідний словник — у [`content/vocabulary_bank.json`](./content/vocabulary_bank.json). Загалом курси містять 2 напрямки, 68 уроків, 332 слова та 328 вправ.

## Основний сценарій учня

1. Відкрийте бота в Telegram та надішліть `/start`.
2. Прочитайте коротке повідомлення про приватність і підтвердьте продовження.
3. Оберіть загальну або бізнес-англійську й пройдіть орієнтовний тест рівня. Результат не є сертифікацією; рівень можна скоригувати вручну.
4. Оберіть денну ціль 5/10/15/20 хвилин і перегляньте план.
5. Оберіть дні, введіть час у форматі `HH:MM` і часовий пояс IANA, наприклад `Europe/Kyiv`.
6. Пройдіть уроки й вправи, пропускайте завдання за потреби; перед наступними уроками повторюйте слова, коли вони заплановані.

Команди: `/help`, `/continue`, `/cancel`, `/progress`, `/profile`, `/plan`, `/settings`, `/pause`, `/resume`, `/support`, `/privacy`, `/delete_me`. `/cancel` скасовує поточний крок, не видаляючи прогрес. Постійне меню дає доступ до уроку, повторення слів, прогресу, плану та налаштувань. `/delete_me` запитує підтвердження, після чого видаляє профіль і пов'язаний прогрес з активної SQLite-бази.

Налаштування `INACTIVE_PROFILE_MONTHS=12` та `TECHNICAL_LOG_RETENTION_DAYS=30` — запропоновані початкові значення з ТЗ, а не автоматично погоджені строки. **Власник має підтвердити або змінити їх перед публічним запуском.** Власник також має до запуску заповнити поля в [`privacy-policy.md`](./privacy-policy.md): особу/організацію, контакт, фактичну мету та правову підставу, аудиторію/вікові обмеження, місце зберігання й доступ, backup-процедуру та обробку звернень. Не публікуйте незаповнену політику й не вважайте її гарантією юридичної відповідності.

## Контент і модерація

Курси в [`content/courses.json`](./content/courses.json) зберігаються як UTF-8 JSON. Кореневий елемент — список курсів; кожен курс має `id`, `language` (`en`), `track` (`general` або `business`), `title`, `description`, `level`, `placement_test` та `lessons`. У кожному тестовому питанні задаються `id`, `level`, `prompt`, `options` і `correct_index`. Уроки мають унікальний `id`, послідовний `order`, `level`, `title`, `objectives`, `explanation`, `vocabulary` та вправи. Слово включає переклад, приклад і переклад прикладу; `transcription` і `part_of_speech` необов'язкові. Вправа має речення з маркером `____`, варіанти, `correct_answer`, заздалегідь підготовлене `explanation` та необов'язкові `translation` і `max_attempts`. Не додавайте згенеровані правила замість перевірених пояснень.

Відео — необов'язковий об'єкт уроку: `{"title":"Назва ресурсу","url":"https://example.org/video"}`. Імпорт приймає лише HTTPS URL із hostname. Додавайте лише перевірені відео з надійних джерел.

Щоб завантажити або відредагувати курс:

1. Модератор з ID із `MODERATOR_IDS` підготує окремий JSON-файл із **одним об'єктом курсу** (скопіює один елемент зі списку `content/courses.json`).
2. У приватному чаті з ботом надішле файл як документ і відповість на нього командою `/admin_import`. Бот перевірить структуру і збереже версію як чернетку; опублікована версія продовжить працювати.
3. `/admin_pending` покаже чернетки на перевірку.
4. Після редакторської перевірки авторизований модератор виконає `/admin_approve course_id:версія`, наприклад `/admin_approve english_general:2`. Нова версія стане активною для учнів.

Непривілейовані користувачі не можуть імпортувати чи затверджувати матеріали. Щоб відредагувати курс, імпортуйте новий JSON із тим самим `id` як наступну версію, перевірте її та затвердьте. Переконайтеся, що правильні відповіді, пояснення, порядок уроків і відео посилання відповідають навчальній меті до публікації.

## Безпека, журнали та резервні копії

- Тримайте токен лише у локальному `.env`; не надсилайте його ботом підтримки, не комітьте і не вставляйте у звіти.
- `MODERATOR_IDS` та `SUPPORT_ADMIN_IDS` мають бути контрольованими числовими Telegram ID.
- Не вмикайте резервне копіювання в неконтрольоване сховище. Для ручної резервної копії зупиніть бота й скопіюйте `data/bot.sqlite3` у сховище з обмеженим доступом і визначеним строком видалення; захищайте та видаляйте копії за окремим графіком.
- Профілі неактивних користувачів очищуються під час старту й щоденно; технічні події без тексту повідомлень очищуються за конфігурованим строком. Файлові журнали ротуються щодня.
- Для міграції/відновлення SQLite спочатку зупиніть бота, збережіть резервну копію і перевірте її на окремій копії файлу.

## Перевірки

```powershell
python -m pytest
python -m telegram_bot.main --check
```

Автотести охоплюють тест рівня, денний план, перевірку повторення, timezone і дні нагадувань, дедуплікацію, валідацію контенту, модераторські версії й збереження/видалення SQLite-прогресу.
