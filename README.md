# Telegram-бот для вивчення англійської

Локальний навчальний застосунок з українським інтерфейсом, загальною та бізнес-англійською, тестом рівня, уроками, вправами, повторенням слів, курсом часів і нагадуваннями. Працює на Python 3.12+, aiogram 3 і SQLite; бот отримує повідомлення через Telegram long polling.

Навчання доступне лише англійською. У застосунку немає оплати, підписок, групових функцій, звітності роботодавцю чи інших мов. Відео додаються як перевірені HTTPS-посилання до уроків.

## Запуск у Windows

1. Встановіть Python 3.12 або новіший і створіть бота через [@BotFather](https://t.me/BotFather), командою `/newbot`. Збережіть токен локально — не надсилайте його в чатах і не додавайте до репозиторію.
2. У PowerShell з папки проєкту створіть та активуйте середовище:

   ```powershell
   py -3.12 -m venv .venv312
   .\.venv312\Scripts\Activate.ps1
   python -m pip install --upgrade pip
   python -m pip install -e ".[dev]"
   ```

3. Створіть `.env` з шаблону та заповніть секрети й Telegram ID:

   ```powershell
   Copy-Item .env.example .env
   notepad .env
   ```

   `BOT_TOKEN` — токен від BotFather. `ALLOWED_USER_IDS` обмежує бота вказаними числовими ID (для особистого запуску впишіть тільки свій ID). `MODERATOR_IDS` — allowlist модераторів; `SUPPORT_ADMIN_IDS` — адміністраторів звернень, наприклад `123456789,987654321`. Дізнайтеся власний Telegram ID надійним способом. Не вставляйте токен у командний рядок, публічні issue чи логи.

4. Необов'язково створіть окрему базу каталогу навчальних матеріалів і перевірте їх без підключення до Telegram:

   ```powershell
   python -m telegram_bot.main --init-content-db
   python -m telegram_bot.main --inspect-content-db
   python -m telegram_bot.main --check
   ```

5. Запустіть бота:

   ```powershell
   python -m telegram_bot.main
   ```

   Для швидкого запуску після налаштування `.env` і встановлення залежностей можна двічі клацнути `start_bot.bat` у Провіднику. Скрипт відкриє PowerShell і виконає наявні перевірки перед запуском. Зупинити бота можна `Ctrl+C`. Тимчасовий розрив мережі під час long polling aiogram повторює автоматично; після `Ctrl+C` бот завершується без аварійного traceback.

   Альтернатива після інсталяції: `english-learning-bot`.

База користувачів бота створюється в `data/bot.sqlite3`, а журнали — в `logs/bot.log`. Схема SQLite має версії та мігрується під час запуску. Дані курсів доступні як у JSON, так і в окремих рядках таблиць `lesson_catalog`, `vocabulary_catalog` і `exercise_catalog`. Каталогові таблиці можна оглянути в будь-якому переглядачі SQLite. Каталоги `data/`, `logs/` і файл `.env` ігноруються Git. Після оновлення вбудованого курсу зупиніть і запустіть бота знову: база з незміненою початковою версією автоматично отримає нову версію курсу, а прогрес учнів залишиться. Курси з уже створеними модераторськими версіями автоматично не перезаписуються. Для роботи бота й нагадувань комп'ютер має бути увімкненим, під'єднаним до мережі, а процес бота має продовжувати працювати. Після зупинки процесу бот не приймає повідомлення й не надсилає нагадування; після перезапуску він продовжить роботу зі збереженої бази.

## Безкоштовний запуск для особистого користування

Для показу на захисті не потрібен платний хостинг. Запустіть long polling на власному Windows-ноутбуці: бот сам встановлює вихідне з'єднання з Telegram, тому домен, публічна IP-адреса й відкриті порти не потрібні.

1. У `.env` укажіть власний числовий Telegram ID у `ALLOWED_USER_IDS`, наприклад `ALLOWED_USER_IDS=123456789`. Це обмежує використання бота цим ID; порожнє значення залишає доступ відкритим для всіх, хто знайде бота. Для модераторських команд за потреби внесіть той самий ID у `MODERATOR_IDS`.
2. Запустіть `.\start_bot.ps1` у PowerShell з папки проєкту або двічі клацніть `start_bot.bat`. Вікно має залишатися відкритим; зупинити процес можна `Ctrl+C`.
3. Відкрийте посилання на бота від BotFather у Telegram, натисніть **Start** і пройдіть onboarding.

Потрібні інтернет, увімкнений ноутбук і запущений процес. Якщо комп'ютер засне або скрипт зупиниться, бот тимчасово перестане відповідати й надсилати нагадування; після запуску він продовжить роботу з `data/bot.sqlite3`. Для особистого запуску це безкоштовніше й простіше за хмарний сервіс; не потрібно намагатися тримати бота в сервісі, який може засинати або не зберігати локальну SQLite-базу.

Для запуску без цієї консолі можна налаштувати Планувальник завдань Windows на старт `start_bot.ps1` після входу до системи. Це не зробить бота доступним, коли ноутбук вимкнено або перебуває в режимі сну.

## Перегляд каталогу матеріалів без Telegram-токена

Створіть окрему базу лише з курсами (без профілів учнів), перегляньте підсумок і відкрийте `data/course_catalog.sqlite3` у DB Browser for SQLite:

```powershell
python -m telegram_bot.main --init-content-db
python -m telegram_bot.main --inspect-content-db
```

Переглядайте таблиці `vocabulary_catalog` та `exercise_catalog`. Команди не потребують `.env` і не змінюють `data/bot.sqlite3`; якщо файл каталогу вже існує, наявні дані не перезаписуються. Вміст також доступний у [`content/courses.json`](./content/courses.json), вихідний словник — у [`content/vocabulary_bank.json`](./content/vocabulary_bank.json). Загалом курси містять 2 напрямки, 68 уроків, 332 слова та 328 вправ.

## Довідник CEFR A1–C2

Початковий архів `English_CEFR_Dataset_Package.zip` не є обов'язковим: скрипт отримує дані з першоджерел. Після встановлення залежностей запустіть у PowerShell з теки проєкту:

```powershell
.\scripts\download_cefr_datasets.ps1
.\.venv312\Scripts\python.exe scripts\build_open_dataset.py
```

Завантажувач зберігає вихідні файли під `data/` (ці дані не додаються до Git), пропускає CEFR-SP за замовчуванням і не обходить авторизацію чи обмеження джерел. Побудовник створює `data/open_training.sqlite3`, а також оновлює [звіт фактичних обсягів](./content/dataset_report.json) і [реєстр джерел та ліцензій](./content/source_registry.json). Повторний запуск після оновлення вихідних файлів перебудовує цю локальну базу; зупиніть бота перед перебудовою.

Перевірений імпорт у звіті містить **184 838** записів значень Open English WordNet, **127 017** унікальних англійських лем і **5 001** унікальне завдання. З 5 001 завдань **997 мають рівень A1–C2, зіставлений точним збігом леми й частини мови з CEFR-J; 4 004 мають невідомий CEFR** і доступні лише через `/open_practice unknown`. Завдання — оригінальні шаблонно сформовані питання за визначеннями й синонімами WordNet трьох типів: введення слова за визначенням, вибір визначення та вибір синоніма. Це не офіційні питання НМТ/ЗНО; автоматичні перевірки підтверджують структуру та однозначність відповіді, але не замінюють педагогічну редактуру. Розподіл за рівнями та темами є у звіті.

### Джерела, ліцензії та межі використання

- **Open English WordNet 2025** — CC BY 4.0; також потрібно зберігати повідомлення про ліцензію Princeton WordNet. Не використовуйте назву Princeton у рекламі та не натякайте на схвалення. Джерело не надає українських перекладів чи рівнів CEFR.
- **CEFR-J Vocabulary 1.5 і Grammar Profile 20180315** — першоджерело дозволяє комерційне й дослідницьке використання з атрибуцією та цитуванням; авторське право Tono Laboratory, TUFS. Grammar Profile має рівневі записи лише частково перекладені з японської.
- **Octanove Vocabulary C1/C2 1.0** — CC BY-SA 4.0; похідні матеріали потребують атрибуції та тієї самої ліцензії.
- **CEFR-SP** — CC BY-NC-SA 4.0. Не завантажується за замовчуванням і не входить до бази, придатної для комерційного використання. Лише для некомерційного розгортання його можна явно запросити через `.\scripts\download_cefr_datasets.ps1 -IncludeNonCommercial`; не вмикайте `CEFR_SP_NONCOMMERCIAL_USE=true` для комерційного бота.

Дані CEFR-J та Open English WordNet не містять українських перекладів, тому `/vocab` і особистий список показують англійське визначення та явно повідомляють про відсутність перекладу. `/word`, `/grammar` і `/practice` залишаються окремими командами для наявного CEFR-J/внутрішнього курсу. Відсутній рівень, переклад, пояснення чи приклад не вигадується.

### Команди тренажера

- `/level` або `/level A1` — змінити персональний рівень; вибір A1–C2 зберігається в профілі.
- `/topics` — каталог опублікованих тем і уроків лише поточного рівня. Якщо уроків рівня немає, бот скаже про це, а не покаже інший рівень.
- `/vocab word` — визначення з відкритого словника лише для точного рівня профілю; `/saveword word`, `/wordlist`, `/remove_word номер` керують особистим списком.
- `/open_practice [A1–C2|unknown] [short|standard|long]` — блок на 5/10/20 різних завдань; відповіді перевіряються одразу, текстові відповіді нормалізуються. ID завдань зберігаються у стані проходження, повтору в межах одного блоку немає.
- `/mistakes` — повтор нещодавніх помилок з відкритого набору. Помилки вбудованих уроків відстежуються окремо.
- `/exam [5|10|20]` — тренувальний блок із таймером 20 хвилин. Він змішує доступні питання тесту рівня/уроків із завданнями відкритого набору; відповіді та пояснення відкриваються лише після завершення. Таймер перевіряється під час наступної відповіді (не перериває чат у реальному часі); активний стан зберігається при перезапуску. Це авторське тренування, не офіційний тест НМТ/ЗНО.
- `/progress` — особиста статистика курсу й відкритих завдань; зафіксовані помилки групуються за темами, а наступна практика спершу пропонує доступні завдання слабших тем. Дані доступні тільки профілю цього користувача.

Поточний банк має три типи завдань WordNet і не є повним іспитовим корпусом: у ньому немає аудіо, довгих текстів для читання, перекладів на українську чи надійно позначених рівнем 4 004 завдань. Команди не подають невідомі рівні як CEFR-рівневі. Перевіряйте першоджерела та умови ліцензій перед повторним використанням або розгортанням.

## Навігація та навчальні режими

Після `/start` учень бачить компактну панель із чотирма кнопками: **Навчання**, **Практика**, **Прогрес** і **Налаштування**. Навчальні дії (новий матеріал, повторення, складні слова, часи й відеоуроки) зібрані у вкладеному меню. Заняття починається лише після вибору конкретного уроку або вправи.

Активний урок і поточна вправа зберігаються в профілі SQLite. `/where` показує поточний крок, `/continue` повертає до підтримуваного активного заняття, а `/cancel` або `/finish` безпечно завершує поточну вправу без позначення незавершеного уроку як пройденого. Натискання головного меню саме по собі не зараховує відповідь.

Помилки в курсних вправах і повторенні складних слів записуються як навчальні поля, а не як повні приватні повідомлення. У розділі складних слів доступні активні помилки й історія; слово зникає з активного списку після трьох правильних відповідей, розділених щонайменше 20 годинами. У налаштуваннях можна очистити журнал.

Курс часів — окремий авторський маршрут із поясненнями, формулами, прикладами, маркерами часу й вправами. Доступність уроків визначається рівнем CEFR профілю; прогрес зберігається окремо. Він не є офіційною програмою CEFR чи НМТ/ЗНО.

Каталог YouTube розташований у [`content/youtube_videos.json`](./content/youtube_videos.json) і містить по одному відео для A1–C2. Бот показує добірку за рівнем незалежно від обраного навчального напряму. Назви й канали звірено з метаданими конкретних відео 08.11.2026; рівні й теми є редакторською добіркою, а не офіційною сертифікацією CEFR. Правила оновлення каталогу описані в посібнику адміністратора.

Матеріали профілю LingoPilot — у [`content/bot_profile.json`](./content/bot_profile.json); підготовану квадратну іконку можна знайти в [`assets/lingopilot-icon.png`](./assets/lingopilot-icon.png). Після налаштування `.env` застосуйте назву, About, опис і приватний список команд через `.\.venv312\Scripts\python.exe scripts\configure_bot_profile.py`. Іконку та вимкнення додавання до груп власник має встановити вручну в `@BotFather`; покрокова інструкція — у [посібнику адміністратора](./docs/administrator-guide.md#профіль-lingopilot-і-приватний-доступ).

## Основний сценарій учня

1. Відкрийте бота в Telegram та надішліть `/start`.
2. Прочитайте коротке повідомлення про приватність і підтвердьте продовження.
3. Оберіть загальну або бізнес-англійську й пройдіть орієнтовний тест рівня. Результат не є сертифікацією; рівень можна скоригувати вручну.
4. Оберіть денну ціль 5/10/15/20 хвилин і перегляньте план.
5. Оберіть дні, введіть час у форматі `HH:MM` і часовий пояс IANA, наприклад `Europe/Kyiv`.
6. Після завершення початкових налаштувань виберіть заняття з головної панелі. Бот не запускає урок автоматично; незавершене заняття можна поновити або скасувати.

Команди: `/help`, `/level`, `/topics`, `/word`, `/grammar`, `/practice`, `/vocab`, `/saveword`, `/wordlist`, `/remove_word`, `/open_practice`, `/exam`, `/mistakes`, `/continue`, `/where`, `/cancel`, `/finish`, `/progress`, `/profile`, `/plan`, `/settings`, `/pause`, `/resume`, `/support`, `/privacy`, `/delete_me`. `/cancel` і `/finish` скасовують поточне заняття, не видаляючи збережений прогрес. `/delete_me` запитує підтвердження, після чого видаляє профіль і пов'язаний прогрес з активної SQLite-бази.

Налаштування `INACTIVE_PROFILE_MONTHS=12` та `TECHNICAL_LOG_RETENTION_DAYS=30` — запропоновані початкові значення з ТЗ, а не автоматично погоджені строки. **Власник має підтвердити або змінити їх перед публічним запуском.** Власник також має до запуску заповнити поля в [`privacy-policy.md`](./privacy-policy.md): особу/організацію, контакт, фактичну мету та правову підставу, аудиторію/вікові обмеження, місце зберігання й доступ, backup-процедуру та обробку звернень. Не публікуйте незаповнену політику й не вважайте її гарантією юридичної відповідності.

## Контент і модерація

Курси в [`content/courses.json`](./content/courses.json) зберігаються як UTF-8 JSON. Кореневий елемент — список курсів; кожен курс має `id`, `language` (`en`), `track` (`general` або `business`), `title`, `description`, `level`, `placement_test` та `lessons`. У кожному тестовому питанні задаються `id`, `level`, `prompt`, `options` і `correct_index`. Уроки мають унікальний `id`, послідовний `order`, `level`, `title`, `objectives`, `explanation`, `vocabulary` та вправи. Слово включає переклад, приклад і переклад прикладу; `transcription` і `part_of_speech` необов'язкові. Вправа має запитання, `correct_answer`, заздалегідь підготовлене `explanation` та необов'язкові `translation` і `max_attempts`; для вибору задаються `options`, а для вільної відповіді — `answer_mode: "text"` та порожній список варіантів. Допустимі рівні — A1–C2. Не додавайте згенеровані правила замість перевірених пояснень.

Урок може містити необов'язковий зовнішній ресурс. Окремий каталог YouTube `content/youtube_videos.json` призначений для прямих посилань на конкретні відео; поля та правила додавання наведені в посібнику адміністратора. Не підставляйте URL пошуку або неперевірене посилання.

Щоб завантажити або відредагувати курс:

1. Модератор з ID із `MODERATOR_IDS` підготує окремий JSON-файл із **одним об'єктом курсу** (скопіює один елемент зі списку `content/courses.json`).
2. У приватному чаті з ботом надішле файл як документ і відповість на нього командою `/admin_import`. Бот перевірить структуру і збереже версію як чернетку; опублікована версія продовжить працювати.
3. `/admin_pending` покаже чернетки на перевірку.
4. Після редакторської перевірки авторизований модератор виконає `/admin_approve course_id:версія`, наприклад `/admin_approve english_general:2`. Нова версія стане активною для учнів.

Непривілейовані користувачі не можуть імпортувати чи затверджувати матеріали. Щоб відредагувати курс, імпортуйте новий JSON із тим самим `id` як наступну версію, перевірте її та затвердьте. Переконайтеся, що правильні відповіді, пояснення, порядок уроків і відео посилання відповідають навчальній меті до публікації.

## Безпека, журнали та резервні копії

- Тримайте токен лише у локальному `.env`; не надсилайте його ботом підтримки, не комітьте і не вставляйте у звіти.
- `MODERATOR_IDS` та `SUPPORT_ADMIN_IDS` мають бути контрольованими числовими Telegram ID.
- Не вмикайте резервне копіювання в неконтрольоване сховище. Для ручної резервної копії зупиніть бота й скопіюйте `data/bot.sqlite3` у сховище з обмеженим доступом і визначеним строком видалення; захищайте та видаляйте копії за окремим графіком.
- Профілі неактивних користувачів очищуються під час старту й щоденно; технічні події без тексту повідомлень очищуються за конфігурованим строком. Файлові журнали ротуються щодня.
- Для міграції/відновлення SQLite спочатку зупиніть бота, збережіть резервну копію і перевірте її на окремій копії файлу.

## Перевірки

```powershell
python -m pytest
python -m telegram_bot.main --check
```

Автотести охоплюють тест рівня, денний план, перевірку повторення, timezone і дні нагадувань, дедуплікацію, валідацію контенту, модераторські версії й збереження/видалення SQLite-прогресу.
