# Документація LingoPilot

Оберіть інструкцію за своєю роллю:

- [Посібник користувача](user-guide.md) — навчання, вправи, прогрес, налаштування і команди учня.
- [Посібник модератора](moderator-guide.md) — перевірка, імпорт і публікація курсів.
- [Посібник адміністратора](administrator-guide.md) — запуск бота, конфігурація, ролі та безпека.
- [Технічна документація та підтримка](operations-manual.md) — архітектура, база даних, потоки, діагностика, резервне копіювання й обслуговування.

Загальна інструкція встановлення проєкту розміщена в [README.md](../README.md). Файл політики приватності — [privacy-policy.md](../privacy-policy.md); перед публічним запуском його потрібно заповнити й перевірити.

Документація описує поточну поведінку коду. У разі розбіжності між інструкцією та застосунком перевірте реалізацію, оновіть документацію й повторно протестуйте відповідний сценарій.
