# Посібник модератора

## Роль і доступ

Модератор готує та перевіряє навчальні матеріали, але не керує BotFather-токеном, серверним процесом чи резервними копіями. Його Telegram ID має бути в `MODERATOR_IDS` у локальному `.env` власника. Зміни цього списку набувають чинності після перезапуску бота.

Команди модерації потрібно надсилати в особистому чаті з ботом. Доступні команди:

- `/admin_import` — імпортувати JSON-файл як чернетку.
- `/admin_pending` — переглянути список чернеток.
- `/admin_approve course_id:версія` — опублікувати конкретну чернетку.

Приклад: `/admin_approve english_general:2`. Версію зручно взяти з повідомлення після імпорту або зі списку `/admin_pending`.

## Підготовка матеріалу

1. Візьміть актуальний курс із [`content/courses.json`](../content/courses.json) або підготуйте новий окремий курс.
2. Збережіть **один JSON-об'єкт курсу** в UTF-8-файлі з розширенням `.json`; не додавайте навколо нього список чи Markdown-блоки.
3. Перевірте ідентифікатори, порядок і зміст уроків, правильні відповіді, переклади, пояснення та посилання. Посилання на відео допускаються лише через HTTPS із hostname.
4. Переконайтеся, що матеріал відповідає межам застосунку: `language` — `en`, `track` — `general` або `business`, рівень — A1, A2, B1, B2, C1 чи C2.
5. Перевірте приклади та вправи редакторськи. У кожної вправи має бути речення з маркером `____`, щонайменше два варіанти, правильна відповідь серед варіантів і зрозуміле пояснення.

Основні поля курсу:

```json
{
  "id": "english_general",
  "language": "en",
  "track": "general",
  "title": "Назва курсу",
  "description": "Короткий опис",
  "level": "A1",
  "placement_test": [],
  "lessons": []
}
```

Для повної структури використайте вже наявний курс як шаблон. Не змінюйте `id` курсу, якщо задум — опублікувати нову версію цього ж курсу. Ідентифікатори уроків, тестових питань, слів і вправ мають бути непорожніми й унікальними у відповідному обсязі. Порядок уроків — унікальне додатне число. Курс має містити тест рівня, уроки й принаймні одну вправу на урок.

## Імпорт і публікація

1. Надішліть JSON-файл у приватному чаті з ботом.
2. Відповіддю на повідомлення з файлом надішліть `/admin_import`.
3. У разі успіху бот підтвердить, що матеріал збережено як чернетку, і покаже ідентифікатор версії. Максимальний розмір файла — 256 КБ.
4. Перевірте чернетки командою `/admin_pending`.
5. Повторно перевірте матеріал у джерелі й опублікуйте потрібну версію: `/admin_approve course_id:версія`.
6. Перевірте курс як учень після публікації. Нова версія активна для нових запитів курсу; попередні опубліковані версії залишаються в базі.

Імпорт виконує структурну перевірку JSON і зберігає нову версію зі статусом `pending`; це не замінює методичну, мовну чи авторську редактуру. У поточному інтерфейсі немає окремої команди видалення або відхилення чернетки. Не затверджуйте неперевірений чи випадково завантажений матеріал.

## Типові помилки

- **«Команда доступна лише модераторам.»** Перевірте, що правильний числовий Telegram ID внесено в `MODERATOR_IDS`, і попросіть власника перезапустити бот.
- **«Відповіддю на цю команду прикріпіть JSON-файл курсу.»** Надішліть `/admin_import` як reply саме на повідомлення з документом.
- **Файл завеликий.** Поточний ліміт — 256 000 байтів; приберіть зайві дані й повторно перевірте курс.
- **JSON/валідація не проходить.** Перевірте кодування UTF-8, формат JSON, обов'язкові поля, унікальні ID, `correct_index`, варіанти вправ і HTTPS-URL.
- **Чернетка не публікується.** Перевірте точний `course_id:version` з `/admin_pending`. Затвердити можна лише наявну чернетку.

Не пересилайте й не просіть токен бота. Для проблем із процесом, базою або конфігурацією звертайтеся до адміністратора/власника.
